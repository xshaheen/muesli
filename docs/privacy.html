Privacy Policy

Last updated: August 11, 2026

Muesli is local-first. Speech-to-text processing runs on your Mac and audio is not sent to a transcription service. Optional hosted cleanup, meeting-note, calendar, update, telemetry, and private iCloud features exchange only the data described below.

What Muesli Does

Muesli is a macOS application for dictation and meeting transcription. It uses on-device machine learning models (CoreML / Apple Neural Engine) to convert speech to text entirely on your Mac.

Data That Stays on Your Device

The following data is created and stored locally on your Mac:

  • Audio recordings — microphone and system audio captured during dictation and meetings
  • Transcripts and meeting notes — stored in a local SQLite database; text can also be copied to your private iCloud database when text sync is enabled
  • Configuration and preferences — stored in a local JSON file. Mode definitions — their names, instructions, activation apps, activation websites and send keys — and history provenance stay in that local file and are not synced to iCloud.
  • Speech-to-text models — downloaded once from public model repositories (HuggingFace) and cached locally

Muesli keeps a one-time copy of your previous configuration as config.pre-modes.json when it converts Writing Styles into Modes, so you can roll back. That file is a copy of your old configuration and therefore contains the same provider API keys; delete it once the upgrade is working.

Optional Cloud Services

Muesli offers optional integrations that connect to external services. These are opt-in and require explicit user action:

  • Hosted dictation cleanup — if you select ChatGPT, OpenAI, OpenRouter, or another configured hosted provider, Muesli sends the transcript and the locally selected style instructions to that provider. Separately enabled App Context is included only when that setting is on. Mode names, activation apps, and activation websites are not sent merely to select a mode and are not added to telemetry.
  • Meeting summarization (OpenAI API / OpenRouter) — if configured, meeting transcripts are sent to the selected API provider to generate summaries. This is governed by the respective provider's privacy policy.
  • Meeting summarization (ChatGPT subscription) — if you sign in with your ChatGPT account, transcripts are sent to OpenAI's API for summarization using your existing subscription.
  • Sparkle update checks — Muesli checks for new versions via an appcast feed hosted on GitHub. No personal data is transmitted.

Private iCloud Text Sync

When enabled, Muesli syncs dictation text, meeting transcripts, notes, summaries, and manual notes through your CloudKit private database. Audio, Writing Style definitions and rules, and local style-selection or cleanup-outcome provenance are excluded from sync.

Google Calendar Integration

Muesli can optionally connect to your Google Calendar to display upcoming meetings in the status bar and auto-detect meeting start times. When you connect Google Calendar:

  • Muesli requests read-only access to your calendar events (event titles, times, and durations)
  • Calendar data is fetched directly from Google's API to your Mac — it does not pass through any intermediary server
  • Calendar data is used only for displaying upcoming meetings and is not stored persistently
  • OAuth tokens are stored in your macOS Keychain, protected by the operating system
  • You can revoke access at any time from your Google Account permissions page

macOS Permissions

Muesli requests the following macOS permissions, each for a specific purpose:

  • Microphone — to capture your voice for dictation and meeting transcription
  • Screen Recording — to capture system audio during meetings (via ScreenCaptureKit) and, only when separately enabled, OCR screen text for dictation App Context. Modes never trigger or use OCR.
  • Accessibility — to paste transcribed text and, when App Context is enabled, read bounded focused-app text and browser URL context. Accessibility is also used, when “Match modes by website” is on and a mode lists a website, to read the address of the page you are dictating into so the right mode is chosen. That address is used only for matching: it is never stored, logged, or sent, and the setting can be turned off.
  • Input Monitoring — to detect the global dictation hotkey
  • Calendar — to read upcoming events from your local macOS calendar (EventKit)

Anonymous Usage Analytics

Muesli uses TelemetryDeck to collect minimal, anonymized usage signals (e.g., which features are used and app launch counts). Dictation completion reports only coarse enum values for transcription backend, paste method, mode-selection source, whether a mode applied, cleanup outcome, and cleanup backend. It never sends bundle IDs, hostnames, app or mode names, mode IDs, prompts, transcripts, URLs, selected text, OCR text, or App Context. Hard-failure diagnostics use a separate allowlist and never include raw error messages, audio, transcripts, meeting or calendar titles, clipboard or screen contents, API keys, auth tokens, local file paths, raw logs, or database contents. TelemetryDeck does not store IP addresses, and identifiers used for anonymous user and session counts cannot be traced back to a person. You can learn more about TelemetryDeck's privacy practices on their privacy page.

Optional Local Debug Logs

Transcript-cleanup debug JSONL is off by default and can be enabled only through Muesli's developer environment flags. It is written locally in the app support directory and may contain bounded transcript, cleanup output, App Context, error text, and the selected mode ID and selection source. The file rotates when it exceeds 5 MB. These debug entries are not sent to TelemetryDeck.

No Personal Data Collection

Muesli does not operate a server that stores your transcripts or audio. Data is transmitted only when you enable or use the optional hosted cleanup, meeting-note, private iCloud text-sync, calendar, update-check, or anonymous telemetry features described above. Local transcription, local cleanup, and local style matching work without sending their content to Muesli.

Open Source

Muesli's source code is publicly available on GitHub under the MIT license. You can inspect exactly what the application does with your data.

Children's Privacy

Muesli is not directed at children under 13. We do not knowingly collect data from children.

Changes to This Policy

If this policy changes, the updated version will be posted here with a revised date. Muesli does not have a mechanism to notify users of policy changes since we do not collect contact information.

Contact

For questions about this privacy policy, open an issue on GitHub or reach out to the maintainer via the repository.
